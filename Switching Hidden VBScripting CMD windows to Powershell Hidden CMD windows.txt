Switching Hidden VBScripting CMD windows to Powershell Hidden CMD windows

VBScripting has been a friend of mine. It has allowed me to leverage Windows command line commands and use them within my Windows programs. It's no secret that some pretty high end stuff has used hidden command windows for years. I always did the same. Imagine my surprise when my Event Viewer Windows Application log started filling with VBScripting "error" messages. To add injury to insult I also started getting HTA "error" messages. OK, so I looked to replace the VBScripting hidden command windows. Microsoft suggests using Powershell. After some gyrations I've got it working, no more pesky "Hey we are doing away with VBScripting" messages but it's not 100% hidden anymore. Occasionally and inexplicably the Powershell icon will pop-up fully or partially on the Taskbar. I've discovered that things like Ping are better done using the Comspec variable under a Powershell wrapper. That is part of the pop-up problem but I digress. Why not just use the native Powershell equivalent of a Ping? Well, because it basically takes over the rest of the machine when you run 20 or so in a row, one after the other. Your mouse will get funky and some programs will suddenly start moving to the top order of the windows. In other words, it ain't stable. So what I have found is basically this as my command line:

powershell -WindowStyle Hidden -Command CMD.EXE /C "ping -n 1 -4 8.8.8.8>%TMP%\YourResults.txt"

I use variables in that line but this should give you an idea of what you end up with. It will be in your temp folder. I run it minimized and wait until it's finished. Most of the time it's invisible. Most of the time. It is stable though and doesn't cause the mouse to act up or anything. As a disclaimer, I'm not totally convinced the -Command helps in that command line. The line will work with or without it.
